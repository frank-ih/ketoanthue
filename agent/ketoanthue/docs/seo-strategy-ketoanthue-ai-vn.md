> Dedicated domain for the AI Accountant agent.
> Last updated: 2026-04-18

## 1. Domain Purpose

**ketoanthue.ai.vn** is the standalone product site for the AI Accountant — an AI-powered accounting & tax compliance assistant for Vietnamese SMBs. It owns the full funnel: awareness (blog) → consideration (product pages) → conversion (signup).

**agentclan.co** repositions as the agent platform/marketplace. It should NOT compete in accounting content — instead it links to ketoanthue.ai.vn as a featured agent.

### Domain Architecture

```
ketoanthue.ai.vn
├── /                           → Product homepage (Aiwen landing)
├── /blog                       → Blog listing
├── /blog/{category}/{slug}     → Blog articles
├── /{slug}                     → Promoted pillar articles (root-level)
├── /login                      → OAuth login
├── /chat                       → Chat with AI Accountant
├── /dashboard                  → User dashboard
├── /robots.txt
├── /sitemap.xml
└── /favicon.svg
```

## 9. Content Production Workflow

### SEO Writer Pipeline

```
Topic Brief (manual or AI-generated)
        │
        ▼
SEO Writer handle_task()
  ├── mode: content_creation
  ├── query_enhancement → keyword research
  ├── content_brief → outline generation
  ├── generation → markdown article
  ├── guardrails → E-E-A-T quality check
  ├── onpage_seo → title/meta optimization
  ├── aieo_optimization → AI citation readiness
  └── response_format → final output
        │
        ▼
blog.publish_article(result)
  ├── slugify title → URL-safe slug
  ├── mistune → markdown to HTML
  ├── template builder → full page with nav/footer/SEO
  ├── write to disk → /blog/{category}/{slug}.html
  ├── update posts.json manifest
  └── regenerate sitemap + listing
        │
        ▼
Live on ketoanthue.ai.vn
```

### Manual Override Points

- **Topic selection**: Human reviews keyword data and selects topics
- **Category assignment**: Human maps topic to blog category
- **promoted_to_root**: Human decides which articles get root-level URL
- **Quality review**: Human spot-checks E-E-A-T scores before publish
- **Content refresh**: Scheduled monthly for top performers
